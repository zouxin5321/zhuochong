# 路线图

平台化分三步走。**v0.1 只做资源包插件**，脚本能力在沙箱与权限模型就绪后再开。

## v0.1（当前）

- [x] 透明置顶窗 + 帧动画 + 拖动 + 位置记忆
- [x] 资源包插件（manifest + PNG 帧表），用户目录覆盖内置
- [x] 插件校验（id 合法、文件白名单、缺字段跳过不崩）
- [x] 托盘：显示/隐藏、打开插件目录、退出
- [ ] 安装包签名与自动更新
- [ ] 插件市场一键安装（下载 zip + sha256 校验 + 解压）
- [ ] 像素级点击穿透（当前窗口矩形会挡住小范围桌面）

## v0.2

- [x] 行为层：单击动作池、双击转圈、连点头晕、发呆自言自语、无交互睡觉、拖拽拎起反应
- [x] 多内置角色（小卓 / 小橘 / 小煤 / 三花），右键切换
- [ ] 插件设置：缩放倍率、音量（如带音效）、置顶开关
- [ ] 多显示器与 DPI 变化处理
- [ ] 动作扩展：`hover`（鼠标悬停反应）、按时段切换（白天/夜间）
- [ ] 插件包版本与 `minHost` 兼容提示（「已安装但不兼容」）

## v0.3（需先完成沙箱设计）

- [ ] 行为脚本：受限 JS 沙箱 + 能力白名单（通知、定时器、只读宿主状态）
- [ ] 数据源联动：任务进度、API 数据驱动动作
- [ ] 插件签名与信任链

判定是否进入 v0.3 的前提：v0.1 有稳定的第三方插件提交，且插件市场有审核流程。否则脚本能力只会放大治理成本。
