# v1.3.1 · 龙焰喵上岗：三连双击召唤全屏十字剑气

第一版公开下载。一只机甲猫骑士住进你的桌面：置顶不挡操作、会呼吸会眨眼、能被打断会睡觉，还能双击放大招。

## 核心玩法

- **单击**：随机动作——跳跃 / 挥剑 / 展翼蓄力 / 翻滚 / 转圈 / 挥手 / 小跑（不会连着重复同一个）
- **双击**：跃起放大招「跃焰斩」，窗口临时放大 + 系统通知播报招式名
- **6 秒内连双击**：剑气逐级升温
  - Lv.1 跃焰斩 · 青焰斜劈
  - Lv.2 霜雷斩 · 蓝色剑气，窗口放大 1.55 倍
  - Lv.3 烈阳斩 · **全屏十字剑气 + 白光爆闪**，窗口放大 1.8 倍
- **按住拖动**：被拎起来悬空挣扎，松手展翼落地，位置自动记忆
- **连点 4 下**（慢节奏）：头晕冒星星
- **放着不管**：9 秒后自己溜达/坐下/眨眼；2 分钟后睡觉，任意操作唤醒

## 安装说明

1. 下载 `zhuochong-v1.3.1-win64.zip`，解压到任意目录（绿色版，无需安装）
2. 双击 `zhuochong.exe` 即可
3. 托盘图标有菜单：显示/隐藏、打开插件目录、退出

> **首次运行被 SmartScreen 拦截？** 点「更多信息 → 仍要运行」。绿色版未做代码签名，属正常现象。

系统要求：Windows 10/11（自带 WebView2）。

## 技术实现

- Tauri 2 宿主（Rust）+ canvas 帧动画渲染，透明置顶窗，内存占用约 30MB
- 角色是**资源包插件**：一张 PNG 帧表 + 一份 `manifest.json`，宿主只读文件、不执行插件代码
- 龙焰喵素材为 AI 立绘 + 程序化动画合成（抠图、形变、特效叠加全部脚本化，可复现）

欢迎来仓库做自己的角色，插件规范见 [docs/PLUGIN_SPEC.md](docs/PLUGIN_SPEC.md)。
